# Справка ScriptCraft Studio

ScriptCraft Studio — среда для скриптов и программ на Python, JavaScript/TypeScript, HTML/CSS, SQL, PowerShell и других языках, с ИИ-помощником. Всё работает на вашем компьютере; проекты хранятся в папке `projects` рядом со студией.

## Начало работы

1. **Проект.** Кнопка с названием проекта в шапке → «Новый проект» (или «Мастер скриптов» — готовые заготовки).
2. **Файлы.** Слева — проводник: «Новый файл», перетаскивание файлов и папок с ПК, `.zip` распаковывается.
3. **Главный файл** отмечен ★ — его запускает кнопка «Запустить» (`Ctrl+Enter`). `Ctrl+Shift+Enter` запускает открытый файл.
4. Всё сохраняется само (значок «✓ сохранено» в шапке). История версий каждого файла — значок часов у файла.

## Запуск программ

- Вывод — во вкладке «Терминал» внизу. Если программа ждёт ввода (`input()`), появится поле ввода.
- **Параметры запуска** (значок ползунков в шапке): аргументы командной строки и переменные окружения — например, токены. Они не попадают ни в ИИ, ни в Git.
- **HTML/CSS** открываются во вкладке «Просмотр», **SQL** выполняется во встроенной базе и показывает таблицы.
- **Пакеты** (значок коробки слева): `pip` и `npm` ставят библиотеки в папку проекта, систему это не трогает.
- **Сборка .exe**: «Экспорт» → «Собрать .exe» — Python-проект становится одной программой Windows.

> **Безопасность.** Программы запускаются с вашими правами. Если код удаляет папки, меняет реестр, скачивает и запускает файлы, читает пароли браузера и т.п., студия покажет, что нашла, и спросит ещё раз. Запускайте чужой код, только если доверяете ему.

## Редактор

- Подсказки и переход к определению (`F12`), переименование во всём проекте (`F2`), быстрые исправления (`Ctrl+.`).
- Проверка и форматирование: **Ruff** для Python, **ESLint** и **Prettier** для JavaScript (`Shift+Alt+F`).
- Разделённый редактор (`Ctrl+\`), поиск по проекту (`Ctrl+Shift+F`), переход к файлу (`Ctrl+P`).
- Сниппеты — значок `{}` в шапке; Emmet в HTML/CSS.
- Markdown: просмотр с формулами (`$x^2$`) и диаграммами Mermaid, экспорт в HTML.
- **Горячие клавиши** можно поменять: значок клавиатуры в шапке → нажмите на сочетание.

## Отладка

`F5` — запустить отладку (Python и JavaScript). Точки останова — щелчок слева от номера строки; правый щелчок — условие или «логпоинт» (печатает сообщение без остановки). `F10` — шаг, `F11` — войти, `Shift+F11` — выйти, `Shift+F5` — стоп. Во время паузы видно переменные, можно добавить выражения для наблюдения и навести мышь на переменную в коде.

## Тесты

Вкладка «Тесты»: файлы `test_*.py` запускает **pytest**, `*.test.js` / `*.spec.ts` — `node --test`. Красный тест открывается на упавшей строке. Флажок **«Покрытие»** показывает, какие строки выполнили тесты: зелёная полоска у номера строки — выполнена, красная — нет.

## Блокноты Jupyter

Файлы `.ipynb` открываются как блокнот: ячейки кода и текста, `Shift+Enter` — выполнить ячейку. Графики matplotlib показываются прямо под ячейкой. «Прервать» останавливает долгую ячейку, «Перезапуск» очищает переменные. Кнопка **«Переменные»** показывает всё, что сейчас есть в блокноте (имя, тип, размер, значение); **«Экспорт»** сохраняет блокнот скриптом `.py` (ячейки `# %%`) или веб-страницей `.html` с результатами и графиками.

## Git

Значок ветки слева (`Ctrl+Shift+G`): изменения, коммиты, ветки, слияние с разбором конфликтов, история файла, отправка на GitHub. «Опубликовать на GitHub» создаёт репозиторий через GitHub CLI.

## ИИ-помощник

Панель справа. Ключ Gemini — значок чипа в шапке → «Нейросети»; там же можно подключить локальную модель **Ollama** или свой сервер.

- **Чат** отвечает на вопросы; кнопка «Создать файлы» переносит код из ответа в проект.
- **Агент** (переключатель в чате) сам создаёт, правит, переименовывает и удаляет файлы и запускает код, но **спрашивает перед каждым действием**; покажет план, если задача большая. Удалённый агентом файл можно вернуть: проводник → «История версий и удалённые файлы». «Шагов» — сколько шагов агент может сделать за задачу; «без лимита» — пока не закончит или вы не нажмёте «Стоп».
- **Файлы вне проекта** агент читает и меняет по полному пути, например `C:\Users\Имя\Desktop\заметки.txt`, — только с вашего разрешения, и студия спрашивает **каждый раз**, даже после «Разрешить всё». Перед перезаписью старая версия копируется в папку резервных копий (`agent\…`). Папка студии, файлы `.env`, Windows и Program Files агенту недоступны.
- «Исправить с ИИ» появляется после ошибки запуска.

> **Что уходит в ИИ.** В выбранную нейросеть отправляется ваш вопрос и, если включён контекст «Файл» или «Проект», содержимое файлов проекта, а также файлы вне проекта, которые агент прочитал с вашего разрешения. Файлы `.env`, параметры запуска и ключи не отправляются никогда. С Ollama всё остаётся на вашем компьютере.

## Дизассемблер

Добавьте `.exe` / `.dll` (или ELF / Mach-O) в проект кнопкой «Добавить файлы с ПК» или перетащите его в проводник — он сразу откроется в дизассемблере (потом — из списка файлов внизу проводника). Студия покажет заголовки, секции, импорт и код на ассемблере. Поиск по инструкциям, переход по адресам `jmp`/`call`, правка байтов и **замена инструкции на ассемблере** (двойной щелчок по строке: `nop`, `jmp 0x401020`, `mov eax, 1` — студия покажет байты, добьёт короткую инструкцию `nop` и предупредит, если длинная затрёт следующие). Исходный файл сохраняется как `.bak`.

## Программы на ПК

Значок окна в шапке: установленные программы (поиск, проверка, «Починить», открыть папку), обновления через **winget**, вкладка «Автозагрузка» — включить и выключить программы, которые стартуют с Windows.

## Резервные копии

Раз в день студия сохраняет все проекты в `Документы\ScriptCraft Studio Backups` (настраивается в окне проектов — кнопка с названием проекта в шапке → «Резервные копии»). Удалённые файлы — в «Истории» (значок часов слева).

## Обновления и проблемы

Значок «i» в шапке:

- **Обновления** — укажите репозиторий GitHub с релизами; установленная студия обновится сама, проекты и ключи останутся.
- **Сообщить о проблеме** — отчёт с версией, системой и журналом ошибок; ключи и имя пользователя вырезаются. Журналы — в папке `logs`.
